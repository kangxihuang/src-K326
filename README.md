# (附文档)Springboot2+Vue3+MySQL 旅游社交与结伴平台

**技术栈**：Springboot2、Vue3、MySQL

### 系统简介

TravelBuddy 旅游社交与结伴平台是一套基于 SpringBoot2 + Vue3 前后端分离架构的完整源码系统。平台围绕旅游社交场景，提供行程发布与结伴、动态分享、费用AA分摊、安全预警等核心能力，包含普通用户端与管理员端两大角色，覆盖旅游出行前、中、后全流程闭环管理。
 
### 核心功能
 
### 普通用户端

- 注册与登录：支持用户名+密码注册登录，密码采用 MD5 加密存储，登录成功后签发 JWT Token 用于后续接口鉴权

- 个人资料管理：查看个人基本信息，修改昵称、头像、个人简介、兴趣标签（用逗号分隔多个标签）等资料

- 实名认证：填写真实姓名与身份证号，模拟对接第三方实名认证接口，认证成功后更新用户实名状态

- 紧急联系人设置：填写紧急联系人姓名与电话，用于行程安全预警时同步通知

- 行程发布：创建旅游行程，填写标题、目的地、行程描述、出发日期、结束日期、最大人数、兴趣标签、封面图等字段

- 行程列表浏览：分页查看全部行程，支持按关键词（标题/描述模糊匹配）、目的地、状态筛选

- 行程详情查看：查看行程完整信息，包括发起人昵称、头像、实名认证标识、当前已加入人数/最大人数

- 申请加入行程：向行程发起人提交加入申请，可附带留言信息，同一行程不可重复申请

- 行程申请处理：行程发起人可查看申请列表，通过或拒绝申请；通过后自动增加行程当前人数，满员后行程状态自动变为已满

- 我的行程：查看我发起的行程列表，按创建时间倒序排列

- 智能行程推荐：基于兴趣标签匹配度（权重0.5）、目的地匹配度（权重0.3）、时间冲突检测（权重0.2）三维度计算相似度得分，推荐招募中且未申请过的行程，按得分降序返回

- 动态发布：发布旅游图文动态，支持填写文字内容、所在位置、经纬度坐标，可上传多张图片并按顺序展示

- 动态列表浏览：分页查看已审核通过的动态，支持查看指定用户的个人动态列表

- 动态点赞/取消点赞：对动态进行点赞或取消点赞，实时更新动态点赞数

- 动态评论：对动态发表评论，评论列表按时间正序展示，显示评论者昵称与头像

- 我的足迹：记录并查看个人旅行足迹列表，支持新增足迹记录和删除足迹

- AA账单创建：创建费用分摊账单，填写账单标题、总金额、关联行程、分摊模式（均摊/按项目分摊），可添加多个消费明细项目

- 消费明细管理：每个账单下可添加多个消费项目，填写项目名称、金额、支付者，并为每个项目指定参与分摊人及分摊金额

- 账单列表与详情：分页查看我创建或参与的账单，查看账单完整信息（创建者、关联行程、分摊模式、状态、消费明细、各参与人支付状态）

- 账单结算：对账单执行结算操作，将账单状态更新为已结算

- 账单PDF导出：将账单详情（含摘要信息、消费明细、参与人分摊表）导出为 PDF 文件下载，支持中文显示

- 发起支付：对账单或账单明细项发起支付，填写收款人、支付金额、支付方式（微信/支付宝）、备注，生成待支付记录

- 确认支付：模拟支付回调，确认支付成功后生成交易流水号（微信WX前缀/支付宝ZFB前缀），更新账单参与人支付状态为已付，并发送支付成功通知给收款人

- 取消支付：对待支付的支付记录执行取消操作，状态更新为已取消

- 我的支付记录：分页查看我发起或收到的支付记录，显示支付人、收款人、金额、支付方式、状态、关联账单标题

- 账单支付记录查询：查看指定账单下的全部支付流水记录

- 通知列表：分页查看我的通知消息，按时间倒序排列

- 未读通知计数：实时获取未读通知数量

- 通知标记已读/全部已读：单条标记已读或一键全部标记已读

- GPS行程偏离检测：提交当前位置坐标与行程目的地坐标，后端使用 Haversine 公式计算两地距离（公里），超过设定阈值（默认50公里）时触发偏离预警，自动生成安全预警通知，并返回紧急联系人信息

- 图片上传：支持单张图片上传，返回可访问的图片 URL 地址

- 多图片上传：支持一次上传多张图片，返回图片 URL 地址列表
 
### 管理员端

- 仪表盘统计：展示平台核心数据总览，包括用户总数、行程总数、动态总数、账单总数

- 用户管理：分页查看全部用户列表，支持按昵称/用户名模糊搜索，查看用户详情（含实名认证状态、紧急联系人信息）

- 用户状态管理：启用/禁用用户账号，禁用后该用户无法正常登录系统

- 用户删除：删除违规用户账号

- 行程管理：分页查看全部行程，支持按关键词、状态（招募中/已满）筛选，可编辑行程信息或删除违规行程

- 动态管理：分页查看全部动态（含未审核/已屏蔽），支持按内容关键词搜索，可修改动态状态（审核通过/屏蔽）或删除违规动态

- 账单管理：分页查看平台全部账单，查看账单详情（含消费明细与参与人分摊信息），可删除违规账单
 
### 技术栈

后端框架Spring Boot 2.x
ORM 框架MyBatis-Plus（含分页插件）
权限认证JWT（jjwt）+ 拦截器 + 自定义注解 @AuditOperation 审计日志
前端框架Vue 3
状态管理Vuex / Pinia（视前端代码为准）
构建工具Vite
数据库MySQL（含 tb_user、tb_trip、tb_trip_member、tb_moment、tb_moment_image、tb_moment_like、tb_moment_comment、tb_bill、tb_bill_item、tb_bill_participant、tb_payment_record、tb_notification、tb_footprint、tb_audit_log 等核心数据表）
PDF 生成iText PDF（支持中文）
工具库Hutool（MD5加密、ID生成）
文件存储本地磁盘存储（可配置上传路径）
